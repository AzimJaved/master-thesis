\section{Motivation}
\begin{frame}{Motivation}
  \begin{itemize}
    \item Similar to the Interspeech 2025 paper. https://arxiv.org/pdf/2505.24721
    \item Curiousity about how a transducer model, more involved than CTC, would behave on memristor.
    \item Study the impacts of offloading various components of the transducer model to device.
    \item Study the actual impact of noise
    \item Performance impact on Lexfree vs Tree searches.
    \item Argue from a LM POV, impact of LM on CTC-RnnT
  \end{itemize}
\end{frame}

\section{Some Prerequisites}
\begin{frame}{Some Prerequisites}
  \begin{itemize}
    \item Memristor programming (programming table from paper?) and non idealities
    \item Memristor crossbars and bitlines to represent model weights and thus the need of QAT.
    \item Figure of the model topologies and the components, and the components that can be deployed on device.
  \end{itemize}
\end{frame}

\section{Experiments}
\begin{frame}{Experiments}
  \begin{itemize}
    \item Our matrix is 3 (model types) x 5 (search types) x 3 'stages' (baseline, qat, memristor)
    \item Primary tables could be 1 for each model type. 
    \item Appendix - Tables across models, but same stages for easy comparison.
    \item Device deployment changes the interplay between prior/ILM (higher is better) and LM for performance.
  \end{itemize}
\end{frame}

\section{Future Work}
\begin{frame}{Future Work}
  \begin{itemize}
    \item Error analysis?
    \item denoising (using mlp or something else), search params, LM params, softmax temperature.
    \item ft of model
    \item comparing across different datasets (Data condition)
    \item Effect of noise introduction during model training
  \end{itemize}
\end{frame}
